# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately using GitHub's **Report a
vulnerability** feature on this repository. If that is unavailable, email
[mikel@olasagasti.info](mailto:mikel@olasagasti.info).

Please include the affected version or commit, the impact, and steps to
reproduce the issue. Do not open a public issue for an unpatched vulnerability.

We will acknowledge reports and coordinate investigation and disclosure with
the reporter. Please allow time for a fix before publicly disclosing the
vulnerability.
